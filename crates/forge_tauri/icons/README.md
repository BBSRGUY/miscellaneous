# Forge Icons

This directory contains application icons for the Forge desktop app.

To generate icons, you can use the Tauri icon generation tool:
```bash
cargo install tauri-cli
cargo tauri icon path/to/icon.png
```

Required icon files:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)
