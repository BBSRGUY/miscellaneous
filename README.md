# 📚 Smart PDF & EPUB Reader

A beautiful, feature-rich single-page web application for reading PDF and EPUB files with advanced text highlighting and annotation capabilities.

## ✨ Features

### Core Functionality
- **📖 Dual Format Support**: Read both PDF and EPUB files seamlessly
- **🎨 Multi-Color Highlighting**: Mark important text in 5 different colors (Yellow, Green, Blue, Pink, Orange)
- **💾 Persistent Storage**: All highlights are automatically saved using localStorage
- **🔍 Zoom Controls**: Adjust reading size for comfortable viewing
- **⌨️ Keyboard Shortcuts**: Navigate efficiently with keyboard controls

### Reading Tools
- **Page Navigation**: Easy previous/next page controls
- **Page Counter**: Always know where you are in the document
- **Text Selection**: Natural text selection and highlighting
- **Highlight Management**: Remove individual highlights or clear all at once
- **Responsive Design**: Works beautifully on desktop and mobile devices

## 🚀 Getting Started

### Quick Start
1. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge)
2. Drag and drop a PDF or EPUB file, or click "Choose File"
3. Start reading and highlighting!

### No Installation Required
This is a completely self-contained HTML file that:
- Uses CDN-hosted libraries (PDF.js and EPub.js)
- Requires no server setup
- Works entirely in the browser
- No dependencies to install

## 🎯 How to Use

### Opening a Document
1. **Drag & Drop**: Simply drag a PDF or EPUB file onto the upload area
2. **File Picker**: Click "Choose File" to browse your files

### Highlighting Text
1. Click the **🖍️ Highlight** button in the sidebar
2. Select your preferred color from the color palette
3. Select any text in the document
4. The text will be automatically highlighted in your chosen color
5. All highlights are saved automatically!

### Navigation
- **Next/Previous Buttons**: Click the navigation buttons in the controls bar
- **Arrow Keys**: Use ← and → arrow keys to navigate pages
- **Keyboard Shortcuts**:
  - `Arrow Left/Right`: Navigate pages
  - `Ctrl + H`: Toggle highlight mode
  - `Ctrl + +`: Zoom in
  - `Ctrl + -`: Zoom out

### Managing Highlights
- **Remove Highlight**: Click on a highlighted text (when not in highlight mode) and select "Remove Highlight"
- **Clear All**: Click the 🗑️ Clear button in the sidebar to remove all highlights

### Zoom Controls
- Use the **🔍- and 🔍+** buttons to adjust document size
- Current zoom level is displayed in the controls bar

## 🎨 Color Options

Choose from 5 beautiful highlight colors:
- **Yellow**: Classic highlighting color, great for key points
- **Green**: Perfect for definitions or important concepts
- **Blue**: Ideal for examples or references
- **Pink**: Great for questions or items to review
- **Orange**: Useful for warnings or critical information

## 💡 Tips & Tricks

1. **Organize Your Notes**: Use different colors for different types of information
2. **Persistent Highlights**: Your highlights are saved per file and will remain even if you close the browser
3. **Mobile Friendly**: The reader works great on tablets for comfortable reading
4. **Quick Navigation**: Use keyboard shortcuts for faster reading
5. **File Management**: Close the current document to load a new one
